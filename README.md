# Expiry Alert Pro - Landing Page & Dashboard

**AI-powered inventory tracking app with ML Kit scanning**

## 🚀 Features

- ✅ Interactive Product Simulator with SAFE status indicator
- ✅ Glassmorphism Navigation Bar
- ✅ Scroll-triggered animations (Intersection Observer)
- ✅ Dark/Light theme with LocalStorage persistence
- ✅ Privacy Policy with Table of Contents & Search
- ✅ Inventory Dashboard Mockup (CSS Grid)
- ✅ Material 3 Design System
- ✅ 100% Vanilla JavaScript (No frameworks)

## 🎯 Quick Start

1. Open `index.html` in a modern browser
2. Test the product simulator
3. Toggle dark/light theme
4. Open `privacy-policy.html` to test search & TOC
